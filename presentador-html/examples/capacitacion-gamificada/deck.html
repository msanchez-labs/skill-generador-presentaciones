Las 3 piezas de un buen prompt

Contexto

Qué archivo, qué stack, qué existe.

Intención

Qué quieres lograr y para quién.

Restricciones

Estilo, límites, pruebas esperadas.

¿Cuál prompt dará mejor resultado?

La opción B da contexto (.NET 8), intención (API de clientes) y restricciones (validación, pruebas).

Ciclo de un prompt efectivo

  1. 01

    Escribe

    Contexto + intención + restricciones.

  2. 02

    Revisa

    Lee la propuesta antes de aceptar.

  3. 03

    Prueba

    Ejecuta pruebas y valida.

  4. 04

    Itera

    Ajusta el prompt con lo aprendido.
